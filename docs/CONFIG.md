# JSON и Manager — 0.8.0

Основной порядок работы: [сцены, Inspector, предпросмотр и сохранение](AUTHORING.md).

| Файл | Назначение |
|---|---|
| main.json | Автоматический общий снимок всех разделов |
| cards.json | 30 карт, их параметры, описания, цвета |
| decks.json | Три колоды |
| rules.json | Общие правила и лимиты |
| world.json | Метаданные локации, ограничения, таймеры, события |
| events.json | Механики событий, описания, VFX/SFX |
| playeranimations.json | Состояния персонажей и последовательности клипов |
| audio.json | События с 0–N звуками, категории, pitch, задержка |
| vfx.json | Эффекты и траектории заклинаний, общие VFX |
| interface.json | Веера, стрелки, подсветка, размеры и цвета HP |
| presentation.json | Ракурсы камеры, параллакс |
| prefabs.json | Остальные совместимые параметры компонентов |
| assets.json | Генерируемый справочник импортированных ассетов |
| user-settings.json | Личные настройки игрока; находится в persistentDataPath |

Рабочие разделы находятся в `Assets/StreamingAssets/Config`. `main.json` обновляется кнопкой **Сохранить**, а игра читает отдельные разделы. Поля проверяются до записи, включая ссылки на ассеты и связанные ID. Новый звук или эффект сначала добавляется в Unity и назначается в Manager.

Сохранённый набор можно загрузить в Play через **Перезагрузить Config**. Косметика применяется сразу; баланс, таймеры и механики локации — со следующего матча. Steam использует протокол 9 и хеш игрового набора. Косметические различия разрешены.

`world.json` больше не содержит координаты отдельных кресел/столов. Геометрию редактируйте в общих префабах и в `SeatingLayout`. `CardDepthVisual.pointerInfluence` задаётся на карточном префабе.
