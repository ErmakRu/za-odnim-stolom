# Заклинания: существующие VFX и звук

Все эффекты взяты из уже импортированных ассетов `stuff`. Внешние эффекты не скачивались. Частицы адаптированы под Built-in Renderer в `Assets/Presentation/Effects`; оригиналы в ThirdParty сохранены.

| Карта | Визуал и исходный ассет | Звуки Card_Game (начало → завершение) |
|---|---|---|
| S01 Огненный чих | Огненный след Vefects `VFX_Trail_Fire`, короткое пламя WALLCOEUR `VFX_Fire` у цели | Air_Puff_Short_01 → Pop_Big_01 |
| S02 Обнимашки по расписанию | Зелёное кольцо и крестики Lana `Area_heal_green` | Water_Enhance_01 → Wind_Shimmer_01 |
| S03 Всем по крошке | Маленькие золотые огоньки `Shine_ellow` к каждому противнику, `Flash_star_ellow_purple` при попадании | Air_01 → Pop_Big_02 |
| S04 Технический перерыв | Lana `Area_star_ellow`; маленькие звёзды остаются над существом, пока не потрачена пропускаемая атака | Silly_Squawk_01 → Ding_01 |
| S05 Карманная перестановка | Две рубашки меняются местами, фиолетовый `VFX_Trail_Void`, `Flash_blue_purple` | Air_02 → Air_03 |
| S06 Чужой конспект | Две рубашки летят из центра к владельцу, Lana `Shine_ellow` | Air_Glitter_01 → Ding_02 |
| S07 Слабо ещё две? | Золотые искры Lana `Shine_ellow` у владельца | Wind_Upgrade_01 → Wind_Shimmer_02 |
| S08 Вы ошиблись столиком | Рубашка уходит из слота к владельцу с WALLCOEUR `VFX_Smoke` | Poof_Descend_01 → Poof_01 |

Все префабы заклинаний лежат в `Assets/Prefabs/Editable/Spells`. Для S04 persistentPrefab можно заменить отдельно. У S07 использованы существующие золотые искры, отдельного нового оранжевого кольца не создано.

VFX запускаются после успешного QTE по публичному событию хоста. Отменённая R04 цель не получает эффект. Добор/обмен не раскрывают лица закрытых карт. Повторные снимки состояния не запускают эффект повторно; старые события не проигрываются при подключении. VFX не меняют правила и не задерживают разрешение карты.

В лаборатории нажимайте «Эффект ›», затем «Показать». Масштабы, длительности, звук и частицы меняются в Inspector. Прицеливание по-прежнему без VFX.
