# Состояние 0.5.0

Сохранены сцены 3D-стола, импортированные герои и мебель. Весь игровой интерфейс переведён на uGUI-префабы; карты наследуют базу через варианты типа. Добавлены постоянные ники/HP, нижняя панель брони, один раунд, повтор матча, возврат в лобби, ESC с общей громкостью и эффектами, восемь VFX/звуков заклинаний.

Точки входа: [PREFABS.md](PREFABS.md), [SPELL-EFFECTS.md](SPELL-EFFECTS.md), [PLAYTEST-RU.txt](PLAYTEST-RU.txt). Фактические проверки и ограничения: [QA-REPORT.md](QA-REPORT.md).

Бота, рейтинга, миграции хоста и переподключения нет. Реальный Steam-тест на нескольких ПК остаётся отдельной проверкой.
