# Тестовый билд 0.1.0

## Подтверждённые требования

- Unity, полностью 2D, Windows x64 build.
- Steam online, App ID 480 разрешён пользователем для теста. Собственный App ID пока отсутствует.
- Главное меню, поиск лобби, быстрое подключение, комнаты на 2-4 человека.
- Каждый за себя, несколько коротких раундов с общим счётом.
- Три готовые колоды по 30 экземпляров, примерно 30 уникальных карт в сумме.
- Существа, заклинания и реакции. Предметов нет. QTE обязательно для первых двух типов и отсутствует у реакций.
- Существо атакует при успешном розыгрыше, затем выходит на стол с постоянным эффектом.
- Если цель атаки не назначена, атакуется герой случайного живого противника.
- У фракции несколько разных ролей. Цвет типа карты и цвет роли существа независимы.
- Сначала каталог/PDF, затем реализация по тем же данным. Бот в текущий этап не входит.

## Принятые параметры первого теста

- 3 раунда, +3 очка за победу в раунде, +1 за устранение противника. При равенстве итогового счёта общая победа.
- 30 HP, 5 ячеек, рука до 8 карт, стартовые 5 и добор в начале хода.
- 1 существо и до 1 заклинания либо до 3 заклинаний без существа за ход.
- QTE существа после разрешения первой атаки/выхода завершает ход; уже стоявшие готовые существа атакуют в конце хода. Новое существо второй раз в тот же ход не атакует.
- Атака в существо вызывает ответный урон; если призываемое существо погибает от него, на поле оно не выходит.
- Один общий этап реакций на объявленное действие: до одной реакции от каждого живого игрока, без реакций на реакции. Время 7 секунд, можно пропустить.
- По окончании QTE успешная карта проходит этап реакций, затем разрешается. При срыве карта передаётся заранее показанному случайному живому противнику, при переполнении руки сгорает.
- Базовый таймер QTE 10 + (длина - 2) * 3.3 секунд; 3 ошибки или истечение времени означают провал; промах отнимает 2 секунды.
- Первая версия позволяет локальную игру с передачей управления для проверки без дополнительных Steam-аккаунтов. Это не бот.
- В Steam-варианте владелец лобби рассчитывает правила. Уход хоста заканчивает сессию; миграция хоста пока не реализуется.

## Техническое состояние

- Найден Unity 6000.3.21f1 с Windows Standalone Support.
- Лицензия подтверждена успешными проверками и Windows-сборками.
- Готовы 33 PNG: 30 иллюстраций карт, меню, стол, рубашка. Генерация: встроенный image_gen; промпты — `docs/art-prompts.json`.
- PDF составлен до боевой реализации, затем дополнен всеми иллюстрациями: 22 страницы, 30 уникальных карт, три колоды. Все страницы отрендерены и проверены.
- Реализованы правила всех карт, QTE, реакции, цели, три раунда и общий счёт. Бот не добавлялся.
- Главное меню, справочник карт, выбор колод, локальная передача управления, Steam-лобби, код комнаты, быстрый поиск и авторитетный хост.
- Windows x64: `Builds/Windows-v0.1.0/ZaOdnimStolom.exe`.
- 16 групп проверок, включая 24 полных детерминированных матча на 2, 3 и 4 игроков. Результаты: `output/tests/core-tests.txt`.
- Реальный Steam smoke-test: API Init 480, приватное лобби, метаданные колоды/готовности, запрет старта в одиночку. Тестовая комната закрыта. Результаты: `output/tests/steam-smoke.txt`.
- Первый Windows-билд запускался как отдельное приложение; в Player.log не обнаружены исключения игры.
- Визуальная проверка окна не завершена: computer-use сообщил `SetIsBorderRequired failed ... 0x80004002`, затем пользователь остановил компьютерное управление клавишей Escape. Дальнейшее управление UI не выполнялось.
- Сетевой бой, поиск/вход со второго аккаунта и реальная доставка SteamNetworkingMessages между компьютерами пока не проверены: нужны 2–4 Steam-аккаунта/ПК. Есть пошаговая инструкция для такого теста.
