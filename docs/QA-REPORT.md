# Проверка прототипа 0.4.0

22 сентября 2026. Unity 6000.3.21f1 / Windows x64 / Mono / Direct3D 12.

## Результат

- Сборка Player завершена успешно; 21 группа CoreTests, 115301 проверка условий, включая 24 полных матча для 2/3/4 участников.
- В дополнение к прежним правилам проверены перенос выбранного героя/доспеха/цвета в матч, очистка некорректных значений, сетевой JSON с косметическими данными без раскрытия рук, ограничения команды поворота головы. Успешная и несработавшая реакция различаются для анимации.
- PresentationTests проверяют три ручных ракурса и JSON, раскладки, Canvas, 8 humanoid-ригов, ссылки на контроллер/эффекты/аудио, четыре места лобби и настройку облика.
- 24 сценария Windows Player в 1440 × 810: новое лобби 2/4 места, все 8 героев, смена колоды/модели/доспеха/палитры, сохранение выбора в матче, три камеры, стол, QTE, левый показ и правое наведение, ручные стрелки, попадание, раскладки 2/3/4.
- Лаборатория: запуск без Steam, один EventSystem, JSON roundtrip, бой, все 11 Animator-состояний, цепочка Die → AttackCombo05 и DieRecover, анимированный кириллический титр. Четыре кадра.
- Кадры снимал ScreenCapture самой игры. Лобби, мебель, материалы героев и лаборатория просмотрены; ошибка исходной ориентации костей и FBX-мебели исправлена. Неудачные промежуточные кадры не используются как подтверждение результата.

Отчёты: `output/tests/core-tests.txt`, `presentation-tests.txt`, `render-smoke-v0.4.txt`, `lab-smoke-v0.4.txt`. Иллюстрации: `docs/images/*v0.4.png`. Полные локальные кадры/логи исключены из Git.

## Границы проверки

Steam-лобби, выбор облика и направление взгляда синхронизируются кодом протокола 4. Настоящий матч между разными Steam-аккаунтами на нескольких ПК в этой итерации не выполнен; снимок лобби снят на локальных тестовых участниках. Для онлайна всем нужен Player 0.4.0. Проверьте поиск/код, одинаковые модели у всех участников, QTE/реакции при задержках и выход хоста.

Жесты мыши проверяются вызовами контроллера и raycast, а не полным физическим ручным прогоном. Звуковые ссылки проверены, субъективная оценка громкости не проводилась. В музыкальном слоте лаборатории ambience из Card_Game. Сидячая поза адаптирована из humanoid-рига; исходный набор не содержит отдельного сидячего idle. Табличные правила и 22-страничный PDF 0.3 не изменены и заново не генерировались.

В проекте сохранены исходные ассеты stuff и отдельные адаптации VFX для built-in renderer. Неиспользуемые демонстрационные ресурсы не включаются в Player. Архивы проверяются CRC, размеры и SHA-256 записываются в `output/release-manifest.json`.

## Ограничения проверки

Настоящий Steam P2P-матч между разными аккаунтами/ПК в 0.3 ещё не выполнен. Изображение лобби проверено на тестовых данных без подключения к Steam. Прежний 0.1 Steam smoke проверял создание/закрытие лобби, но не заменяет текущий многопользовательский прогон. Нужно проверить задержки QTE/реакций, поиск/код, доставку событий и отключения с друзьями.

Прогоны контроллера и снимки не заменяют полный ручной тест мышью и всех вариантов перетаскивания, пользовательскую оценку читаемости и баланса. Автоматические игроки в тестах — исполнители команд для проверки правил; игрового бота нет.

3D-модели и наборы VFX/Audio/MotionTitles из другой ветки отложены пользователем. Сейчас серые заглушки, простые эффекты и сигналы; анимации Head/Weapon/героев не подключены. Рука, подписи мира, поиск комнат и локальная настройка пока IMGUI. Нет рейтинга, сохранения матча, переподключения и миграции хоста. Все участники должны использовать 0.3.0/протокол 3.
