# За одним столом

Карточная игра для 2–4 игроков: 3D-стол, ручная камера, QTE, реакции на розыгрыш и один раунд FFA. Три готовые колоды по 30 карт, 30 уникальных карт. Есть Steam-лобби на тестовом App ID 480 и локальный режим с передачей управления.

## Текущая версия 0.8.0 — тестирование в Unity

Откройте проект `SummonersTable` в **Unity 6000.3.21f1**, сцену `Assets/Scenes/MainMenu.unity` и нажмите **Play**. Выберите «За одним ПК», 2–4 участников и начните матч. Отдельная сборка для этого не нужна.

## Настройки через Manager

Откройте **Summoners Table → Authoring**: локация, эффекты/звук, анимации или карты/интерфейс. Выберите Manager в сцене, измените поля Inspector и запустите предпросмотр без Play. Кнопки «Сохранить», «Создать копию» и «Откатиться» работают с выбранным разделом. [Подробная инструкция](docs/AUTHORING.md).

Сохранение обновляет рабочий JSON и общий снимок `main.json`. Игра читает отдельные рабочие файлы. Предпросмотр рассадки поддерживает 1–8 мест; матч остаётся на 2–4.

## Рабочие JSON в Inspector

Выберите JSON в `Assets/StreamingAssets/Config`. Содержимое открывается **в Inspector Unity**: измените текст и нажмите **«Сохранить»**. Сохранение проверяет весь набор файлов. Двойной щелчок тоже открывает Inspector.

| Файл | Назначение |
|---|---|
| cards.json | Карты, числа, описания, цвета типов и групп |
| decks.json | Составы колод |
| rules.json | HP, рука, раунды, лимиты действий, QTE, пределы эффектов |
| audio.json | Звуки игровых действий, громкость, высота и задержка |
| vfx.json | Эффекты и траектории восьми заклинаний, общие VFX |
| world.json | Локация, масштаб кресла и героя, таймеры, диапазон игроков, события |
| events.json | Механики событий локации, описание, VFX и звук |
| playeranimations.json | Последовательности клипов для состояний персонажа |
| interface.json | Веера, HP, стрелки и материалы подсветки |
| presentation.json | Камера и глубина иллюстраций карт |
| prefabs.json | Параметры компонентов общих префабов |
| assets.json | Генерируемый справочник ID импортированных ассетов |

Во время Play нажмите «Перезагрузить Config» в Inspector, главном меню или ESC. Оформление и звук обновятся; баланс применяется перед следующим матчем. Ошибка JSON сохраняет предыдущий набор целиком. При ошибке первоначальной загрузки начало матча блокируется до исправления.

Новый звук сначала импортируйте в Assets, затем выполните **Summoners Table > Config > Refresh asset IDs**. ID можно найти и скопировать прямо в Inspector `audio.json`.

Префабы определяют структуру и оформление; JSON задаёт управляемые параметры. Значения `CardView.Definition` в карточных префабах — предпросмотр, а не источник баланса. Для обновления этих подписей: **Summoners Table > Config > Refresh card prefab previews from JSON**. `Resources/Data/catalog.json` сохранён как исходный каталог поддерживаемых механик; редактировать игровой баланс нужно в Config.

## Префабы

Карты наследуются: `CardBase → CreatureCard / SpellCard / ReactionCard → C01…C18 / S01…S08 / R01…R04`. Каждый вариант содержит полное, компактное и настольное представление.

В мире используются общие `PlayerSeat`, `Chair`, `PlayerAvatar`, `PlayerTarget` и `CreatureSlot`. SeatingLayout создаёт нужное число экземпляров общего HeroSittingPlace → PlayerSeat вокруг стола. Интерьер комнаты сохранён отдельным префабом. Лобби использует четыре экземпляра `LobbyPlayerPanel` и `LobbyPortraitStage`. Остальные экраны, стрелки, журнал, HP и эффекты также сохранены как префабы.

Сцена `Match.unity` предназначена для редактирования окружения. `PresentationLab.unity` позволяет проверить камеру, анимации и VFX. Сохранение камеры в лаборатории пишет в общий `Config/presentation.json`.

## Правила

Лидер выбирает «Волшебники» (по умолчанию 3 заклинания либо 1 существо + 1 заклинание) или «Полководцы» (10 QTE за ход). Реакции бесплатны. Провал QTE не возвращает расход. Пределы усилений и объём иллюстраций включаются в лобби и фиксируются на матч. [Подробности](docs/LOBBY-RULES.md).

Существа атакуют в конце хода. Реакции доступны во время показа карты и QTE, но не на атаку уже стоящего существа. Стрелка в центр выбирает случайного противника. Настройки в главном меню и по ESC регулируют master, эффекты, окружение, голоса, музыку, экран/FPS, шейдер и цвет подсветки. Личные значения сохраняются в user-settings.json.

## Проверки и будущие сборки

`Summoners Table > Validate rules` запускает проверки без сборки. Редакторный сценарий `EditorPlaySmoke.Run` проверяет Play, перезагрузку JSON и 52 игровых/UI-сценария в пакетном запуске Unity.

Для будущего Windows Player предусмотрена внешняя папка `Config` рядом с EXE. `Build Windows` копирует туда настройки; сейчас проверяем проект в редакторе. После добавления нового ассета в будущий Player нужна пересборка, числовые настройки меняются без неё.

Steam использует протокол 9 и хеш карт, колод, правил и механик локации: у участников должен совпадать баланс. Косметические настройки могут различаться. Реальный матч на разных ПК в этой итерации не проверялся.

[Происхождение ассетов](docs/TAVERN-ASSETS.md), [лицензии](docs/THIRD-PARTY.txt). Билды, архивы и кэш Unity исключены из Git.
